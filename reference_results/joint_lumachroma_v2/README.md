# Previously measured reference experiment

These files preserve the historical all-Train v2 experiment, not results generated by the repository refactor. The notebook and ZIP names and SHA-256 identities are recorded in `provenance.json`. Selected weights, metrics, and CV CSVs were copied without numerical changes. The report manifest's output-directory path was removed and an explicit reference-status field added.

The report used 485 / 689 / 900 Train images and 15 / 100 / 100 Test images across LOL-v1 / LOL-v2 Real / LOL-v2 Synthetic. All weights were selected on Train, although the official Test benchmarks had already been inspected in earlier research.

Train coefficient caches, full-resolution predictions, checkpoint binaries, and the source ZIP are deliberately excluded. New runs must write to a separate output directory. Do not edit these references to match a new run.
